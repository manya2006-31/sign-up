# MERN Sign Up & Log In System

A Sign Up and Log In system built with React (React.createElement, no JSX),
an Express REST API, MongoDB and bcrypt password hashing.

## How to run
1. Start MongoDB
2. npm install
3. npm start
4. Open http://localhost:3000

## API Endpoints
- POST /api/signup
- POST /api/login
- GET /api/users
- PUT /api/users/:id
- DELETE /api/users/:id
